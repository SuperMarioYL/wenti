# Before / After — 三联体 pack 把一个 bare-model 草稿抬了多少分

这是 Wenti 的"说服陌生人 star"的单一文件：同一篇公众号草稿，
**bare-model 输出** 与 **三联体 pack 输出** 用同一套 风格评分 rubric
（句式 / 用词 / 节奏 / 视角，0-5）各打一次分。lift 是可证伪的——
如果 rubric 量不出差距，整个"正向 taste 库"的论点就垮在这里。

> 分数由 `wenti score` 的 dry-run 启发式路径算出（未调模型），可本地复现：
> 把下方两段各存成 `.md`，跑 `WENTI_BASE_URL= WENTI_API_KEY= wenti score <file> --pack sanlian --dry-run`。
> 两段即被打分的原文（无 markdown 头，原样打分）。

## 总分对比

| 草稿 | 句式 | 用词 | 节奏 | 视角 | **总分 / 5** |
|---|---|---|---|---|---|
| bare-model 输出 | 0.3 | 0.5 | 2.0 | 2.4 | **1.12** |
| 三联体 pack 输出 | 3.5 | 4.5 | 2.6 | 4.5 | **3.82** |
| **delta** | **+3.2** | **+4.0** | **+0.6** | **+2.1** | **+2.70** |

四个维度全部抬升，总分 +2.70 ≥ 0.5 lift-gate。**用词** 抬得最狠（+4.0）：
bare 稿全是"首先 / 其次 / 综上所述 / 在当今社会"这类套话，零个三联具象词；
三联体稿满是"白菜 / 水汽 / 叶脉 / 围挡 / 钢筋 / 黄昏 / 棋盘"这种可触摸的细节。
**视角** 从全知概述变成第一人称旁观 + 具体时空坐标（"清晨五点四十 /
1998 年 / 那条街"）。**句式** 抬升靠的是连接词起句的消除——bare 稿 11 处
"首先/其次/因此"开头，三联体稿零处。**节奏** 抬升来自段长起伏与短段收束。

## 草稿 A — bare-model 输出（通用 AI 公众号稿）

> 评分：句式 0.3 / 用词 0.5 / 节奏 2.0 / 视角 2.4 — **总分 1.12**

```
随着人工智能的快速发展，越来越多的创作者开始使用 AI 工具辅助写作。AI 写作
带来了很多便利。首先，AI 可以提升写作效率。其次，AI 能够降低创作门槛。最后，
AI 有助于拓宽表达边界。

AI 写作也面临一些挑战。一方面，AI 提供了便利。另一方面，过度依赖可能带来
风险。总之，关键在于如何平衡。在当今社会，技术不断进步，我们需要与时俱进。

综上所述，AI 写作是大势所趋。因此，我们应该积极拥抱这一变化。然而，也有人
担心同质化。不可否认，这是值得注意的问题。不仅如此，而且要善于利用工具。
```

rubric 指出的两个最弱维度 + 三联体 voiced 的改写建议（dry-run 启发式给出）：

- **[句式]** 句长偏均，节奏平直；连接词起句 11 处（-0.3/处）。
  改写锚：`清晨五点四十，菜市场第一缕灯光亮起的时候，老周已经在摊位前站了二十分钟。
  他不吆喝。白菜码得齐整，像一摞没拆封的信，水汽……`
- **[用词]** 感官动词 1 处；AI-slop 套话 16 处（-1.3）。
  改写锚：同上——三联体不在句首堆连接词，靠从句铺陈与短句收束推进，用可触摸的具象词替换"发展/便利/挑战"。

## 草稿 B — 三联体 pack 输出（编辑视角 voiced）

> 评分：句式 3.5 / 用词 4.5 / 节奏 2.6 / 视角 4.5 — **总分 3.82**

```
清晨五点四十，菜市场第一缕灯光亮起的时候，老周已经在摊位前站了二十分钟。他
不吆喝。白菜码得齐整，像一摞没拆封的信，水汽从叶脉上慢慢爬下来。这是他在
那条街的第三十七个冬天。

我是在一个下过雨的下午认识这家店的。门脸小，招牌上的字掉了一半漆，剩一个
"记"字，孤零零悬在那里。老板娘说，店是 1998 年开的，那一年她女儿刚上小学。
现在女儿在上海，做金融，一年回来两次。"她让我关店，"老板娘笑了一下，"我说
再开几年。开到开不动为止。"

城市在拆，也在长。工地围挡后面，一栋新楼正在往上够，钢筋扎得密，像倒立的
树根。骑三轮的人从围挡下过，抬头看了一眼，没停。他赶着去送一单外卖，超时
要扣钱。这座城里这样的人有几十万，他们不读三联，但三联关心他们走过的那条街，
在下午四点的光里，是什么样子。

黄昏是把一座城变得温柔的东西。写字楼的灯一盏一盏亮起来，像棋盘上落下的子。
没有人说话，但所有人都在往前走。这种沉默的、被时间推着的走法，是这座城市
最日常的样子，也是它最容易被忘记的样子。
```

rubric 给出的改写建议（即便三联体稿也不是满分——rubric 不奉承）：

- **[句式]** 句长有起伏（σ=11）；有 1 处长句铺陈。锚：可再多一处短句顿挫收束，把 σ 推过 15。
- **[用词]** 具象/感官词 34 处；感官动词 9 处。锚：已接近范例级，可再替换一两个抽象词为具象物。

## 这说明了什么

1. **rubric 能区分**。同一套尺子，bare 1.12 / pack 3.82，差距可量化、可复现。
   这正是 mvp_plan §8 lift-gate 要证伪的事——如果量不出差距，"正向 taste 库"
   就只是 prompt 工程；现在量得出，pack 的 curated 内容有独立价值。
2. **差距集中在用词与视角**。句式与节奏的抬升幅度较小（三联体与通用稿都可有起伏），
   真正的护城河是用词的具象性 + 视角的第一人称旁观——这正是 hand-curated
   few-shots 注入、bare-model 默认不具备的。
3. **不是 anti-slop 过滤**。bare 稿去掉"综上所述"仍不会变成三联体——它只会
   变成"没有套话的通用稿"。Wenti 装上的是一种**可命名的编辑视角**，不是
   去掉什么。

调真实模型（qwen / doubao / kimi / glm）时，把 `WENTI_BASE_URL` 与
`WENTI_API_KEY` 设上，dry-run 关掉，`wenti score` 会走 LLM-as-judge 路径
（temperature 0.2），lift 的方向应与上面一致，绝对分会有轻微漂移。
